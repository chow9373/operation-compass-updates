# 运营罗盘 v1.4.0

适用于 macOS 15.0 及以上，支持 Apple Silicon 和 Intel。

- 新增 100 项常用电商运营指标，覆盖流量、转化、推广、销售、利润、商品、库存、客户、履约和售后。
- 支持指标计算、目标反推、模拟变化、收藏，以及系统和自建指标的本机编辑。
- 支持指标名称、定义、公式和经营解读搜索，名称结果优先显示。
- 优化设置导航、中文指标名称、卡片对齐、完整标签和深浅色显示。
- 新增软件更新：手动检查、定期检查、可选自动下载与退出时安装；业务计算继续离线使用。

首次迁移：v1.3.5 没有更新模块，请手动安装一次 v1.4.0；之后可从应用菜单或“设置 → 软件更新”检查更新。

安装包为本地 ad hoc 签名，尚未公证。安装时请先退出旧应用，再将 App 复制到 Applications。
