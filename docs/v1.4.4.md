# 运营罗盘 1.4.4

本次更新改进“尺寸修改”的画质、体积控制与设置排版。

- **优先保留画质**：默认 PNG、100% 画质；采用高质量缩放，同尺寸 PNG 避免重复采样，保留透明度、RGB 色彩空间与高位深。
- **按需控制体积**：新增 0% 最小体积至 100% 最大体积的滑块，默认 100%。百分比表示调节位置，不是原文件体积占比。
- **实时预计大小**：按当前尺寸、格式和滑块设置在本机试编码，显示每张图片及总计预计大小，处理后显示实际大小。
- **紧凑整齐的输出设置**：保持卡片宽高，统一标签、输入框、格式、原图选项、滑块与处理按钮的对齐，适配浅色、深色和窄窗口。
- **更新内容提醒**：升级后首次启动展示本版说明，确认后不重复提醒。

尺寸变化需要重采样；PNG 在 100% 时无损编码处理后的像素，低于 100% 时会有损减色。JPG 即使最高画质仍有编码损失。输出大小取决于图片内容、尺寸和格式，可能大于原文件。

图片均在本机处理。默认保留原图；若开启“输出成功后删除原始文件”，仅在成功输出后移入废纸篓，可恢复。

macOS 14 或以上；支持 Apple Silicon 和 Intel。请在“应用程序”中的运营罗盘检查更新，下载后选择“安装并重启”。
