# 运营罗盘 1.4.1

本次更新优化图片尺寸修改与窗口显示体验。

- 新增“输出成功后删除原始文件”：仅在新图片成功输出并验证后，将对应原图移入废纸篓；输出失败时保留原图。
- 删除原图选项会记住上次的勾选或取消选择，重启软件后继续沿用；首次安装默认关闭。
- 宽窗口与全屏下，删除原图设置与输出格式并排；窄窗口自动调整布局。
- 图片工作区保持固定高度，多任务以列表展示并在容器内滚动。
- 统一窗口材质：主侧边栏使用原生毛玻璃，右侧页面和内容卡片保持不透明背景。

支持 macOS 15 或更高版本，适配 Apple Silicon 与 Intel。图片仍在本机处理，输出始终生成新文件。
